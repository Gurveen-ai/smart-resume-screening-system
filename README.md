# Smart Resume Screening System using NLP and BERT

## Project Overview

This project compares a resume and job description using NLP techniques to evaluate candidate-job matching.

## Features

* PDF text extraction
* TF-IDF similarity scoring
* BERT semantic similarity scoring
* Technical skill extraction
* Missing skill identification

## Technologies Used

* Python
* PyPDF2
* NLTK
* Scikit-learn
* Sentence Transformers

## Output Example

* TF-IDF Match Score: 34.86%
* BERT Semantic Score: 81.40%

## Key Insight

TF-IDF measures keyword overlap, while BERT captures semantic similarity between resume and job description.

## Future Improvements

* Streamlit web app deployment
* Resume ranking for multiple candidates
* Named Entity Recognition for advanced skill extraction
